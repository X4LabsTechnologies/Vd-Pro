# 🚀 Vd-Pro - Enterprise Video Extraction Platform

Production-ready video extraction platform built with Node.js, Playwright, and modern streaming technologies.

## ✨ Features

- 🔐 Advanced proxy management with health checks
- 🍪 Session persistence with cookie management
- 🎭 Dynamic stealth fingerprinting
- 🖱️ Natural human interaction simulation
- ⚡ Efficient context pooling
- 📊 Multi-strategy video extraction
- 💾 3-level cache system (L1/L2/L3)
- 🔄 Circuit breaker pattern
- 📈 Prometheus metrics
- 🔒 SSRF protection
- 🎬 Support for m3u8, mp4, webm formats
